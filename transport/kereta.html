1. Persiapan

  1. Jalankan Claude Code dengan claude --chrome (atau claude --chrome --continue untuk melanjutkan). Tanpa itu, alat browser tidak tersedia dan tarif tidak bisa dicek.
  2. Buka Brave/Chrome dengan ekstensi Claude in Chrome yang sudah login. Kalau muncul pilihan beberapa browser, pilih browser yang sedang kamu pakai.
  3. Pastikan tanggal benar. Cek nama harinya, karena 19 Des 2026 ternyata Sabtu, bukan Jumat.

2. Jadwal (168Railway, GAPEKA 2026)

  1. Halaman relasi: https://168railway.com/gapeka-2026/relasi/jakarta-yogyakarta dan …/yogyakarta-jakarta. Ganti nama kota, mis. jakarta-surabaya, jakarta-malang. Isinya daftar kereta, jam di stasiun pertama/terakhir, dan sebagian kelas.
  2. Halaman per kereta: https://168railway.com/gapeka-2026/ka/<nomor>-<nama>, mis. …/ka/184-fajar-utama-solo. Kereta fakultatif memakai akhiran -fakultatif (…/ka/80f-gajayana-fakultatif). Dari sini didapat stasiun singgah (Jatinegara, Bekasi, Cikarang), stasiun akhir, dan apakah Jatinegara benar-benar berhenti atau hanya lewat.
  3. Pembatasan: situs ini membalas HTTP 429 kalau terlalu banyak permintaan. Ambil halaman satu per satu, sekitar 15 per sesi agent, dan ulangi yang gagal belakangan.
  4. Banyak kereta tidak berawal/berakhir di kota tujuan (mis. lanjut ke Solo/Malang). Catat jam di stasiun Jakarta dan di stasiun kota tujuan saja.

3. Kelas

  • Paling akurat: booking.kai.id (langkah 4). Hasil pencarian menampilkan semua varian, termasuk Luxury (nomor berakhiran L), Panoramic (PC), Compartment (CS), Priority (P), dan KA tambahan.
  • Cadangan: Wikipedia (id.wikipedia.org/wiki/Kereta_api_<Nama>). Tandai dengan garis putus di halaman.
  • tiket.com (403) dan Traveloka (halaman template) tidak bisa dibaca otomatis.
  • booking.kai.id hanya menulis "Ekonomi" tanpa membedakan Ekonomi Premium.

4. Tarif (booking.kai.id lewat Claude in Chrome)

  1. Buka URL pencarian ini di tab baru, satu kombinasi stasiun per kali: 
    https://booking.kai.id/?origination=JNG&flexdatalist-origination=JATINEGARA&destination=YK&flexdatalist-destination=YOGYAKARTA&tanggal=18-Desember-2026&adult=1&infant=0&submit=Cari+%26+Pesan+Tiket
    Ganti kode stasiun, nama stasiun (huruf besar), dan tanggal (DD-Bulan-YYYY, bulan dalam bahasa Indonesia).
  2. Jangan pakai fetch() dari script. Cloudflare membalas 403. Buka halaman dengan navigasi biasa, tunggu sekitar 3 detik, lalu baca hasilnya.
  3. Ambil daftar subkelas yang masih tersedia dengan script ini (di tab hasil pencarian): 
    [...document.querySelectorAll('.name')].map(n => {
  let c = n; for (let i = 0; i < 8 && !/Rp/.test(c.textContent); i++) c = c.parentElement;
  const t = c.textContent.replace(/\s+/g, ' ').trim();
  if (/Habis/.test(t)) return null;                       // lewati subkelas yang habis
  const nm = n.textContent.replace(/\s+/g, ' ').trim();   // mis. "TAKSAKA LUXURY (32L)"
  const no = (nm.match(/\((\w+)\)$/) || [])[1];
  const k = t.match(/(Eksekutif|Ekonomi|Bisnis)[^()]*\((\w+)\)/) || [];
  const tm = t.match(/\d\d:\d\d/g) || [];
  const rp = +((t.match(/Rp ([\d.]+)/) || [])[1] || '0').replace(/\./g, '') / 1000;
  const sisa = (t.match(/Tersisa (\d+)/) || [])[1];
  return `${no} ${k[1]} ${tm[0]}-${tm[1]} ${rp}rb${sisa ? ' sisa' + sisa : ''} [${nm}]`;
}).filter(Boolean).join('\n')
    Outputnya bisa terpotong kalau terlalu panjang. Kalau begitu, ambil sebagian dengan .split('\n').slice(30).
  4. Urutan pencarian supaya tidak berulang:
    1. Dari/ke Jatinegara dulu. Ini mencakup semua kereta yang berhenti di Jatinegara.
    2. Lalu Gambir, untuk kereta eksekutif yang hanya lewat Jatinegara.
    3. Lalu Pasar Senen, hanya untuk kereta yang tidak berhenti di Jatinegara.
    4. Ulangi untuk tiap stasiun di kota tujuan.
  5. Per kereta, catat harga termurah yang masih tersedia untuk Ekonomi dan Eksekutif (subkelas yang lebih murah biasanya sudah habis), plus Luxury/Panoramic/Compartment/Priority kalau ada, dan sisa kursi kalau sedikit.
  6. Kereta yang habis: cek hari yang sama seminggu kemudian dan tulis di bawah tarifnya.
  7. Tulis tanggal pengecekan. Harga musim libur berubah cepat.

6. Membangun tab

  • Data tiap kereta: {n, no, j:[[stasiun, jam]…], y:[[stasiun, jam]…], c, kw, kx, f, tmb, x}. j = singgah di Jakarta sesuai urutan perjalanan, y = di kota tujuan, c = kelas dari sumber utama, kw = dari Wikipedia, kx = kelas tambahan dari KAI, f = fakultatif, tmb = KA tambahan.
  • Tarif: objek per arah {nomor: {eko, eks, lux, pan, cmp, pri, s}}. Nilai 0 berarti habis.
  • Tab rute ⇄ Yogya dibuat dengan makeRoute({...}) lalu didaftarkan di ROUTES (lihat contoh Mlg). Isi: data, tarif, nama kota, stasiun kota itu, stasiun yang diutamakan, dan judul ringkasan. Salin satu <section class="pane">, ganti akhiran id-nya (mis. Mlg), lalu tambah tombol tab. Sisi kedua bisa diganti lewat home: {name, stations} (contoh: tab Jakarta ⇄ Surabaya). Cara tercepat mengumpulkan data: jalankan script pengambil di setiap kombinasi stasiun booking.kai.id dan simpan hasilnya di localStorage agar tidak hilang saat pindah halaman.
